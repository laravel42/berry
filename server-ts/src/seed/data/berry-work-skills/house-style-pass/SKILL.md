# House Style Pass

## When to use

Content from several writers needs to read as one voice, or no style guide exists.

Not for: Brand identity design.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Editor.

## Gather first

- The style guide, if any.
- Sample documents.

## Deliverable

Produce the document conformed to style with a note of rules applied, or a short style guide: voice, spelling variant, numbers, dates, capitalisation, inclusive language, and preferred terms.

## Steps

1. Read the style guide, or infer rules from the best existing documents.
2. Apply rules consistently.
3. Record decisions on cases the guide does not cover.
4. Propose additions to the guide.

## Quality checks

- Rules are applied the same way throughout.
- New decisions are recorded for next time.

## Stop and hand to a person when

- Style rules conflict with legal or accessibility requirements.

## Avoid

- Do not invent rules and present them as house style.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

The document reads as one voice and the guide is better than before.
