# Structured Interview Plan

## When to use

A scorecard exists and interviews are about to be scheduled.

Not for: Contacting or scheduling candidates.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Recruiter.

## Gather first

- Scorecard.
- Stages, interviewers and time per stage.
- Any work sample or task.

## Deliverable

Produce an interview plan: stages, who interviews, timing, questions per criterion with follow-ups and what a strong answer contains, a work sample if used, and accessibility adjustments offered to all.

## Steps

1. For each criterion write one behavioural or situational question.
2. Add two neutral follow-up prompts.
3. Describe what a strong, adequate and weak answer contains.
4. Keep any work sample short, paid if it is substantial, and relevant.
5. Write an opening script and the candidate's chance to ask questions.

## Quality checks

- Every candidate gets the same core questions.
- No question touches family, health, religion, age or origin.
- Total time is respectful of candidates.

## Stop and hand to a person when

- A work sample would be long or unpaid.

## Avoid

- Do not use brainteasers or trick questions.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

Any interviewer could run the stage from the plan.
