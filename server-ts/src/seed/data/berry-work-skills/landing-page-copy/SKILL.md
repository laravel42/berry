# Landing Page Copy

## When to use

A page for an offer, event, campaign or cause needs words.

Not for: Page layout and build; describe sections, a designer or engineer builds them.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Content Writer.

## Gather first

- Audience, offer and the single action the page asks for.
- Positioning or message hierarchy.
- Proof available: testimonials with consent, figures with sources.

## Deliverable

Produce page copy in sections: headline and subhead options, the problem, the offer, how it works, proof, objections answered, the call to action, and any required legal lines.

## Steps

1. Write the headline as the main benefit in the reader's words.
2. Order sections the way the reader's questions arrive.
3. Use only proof the workspace has; mark gaps as [PROOF NEEDED].
4. Answer the top three objections plainly.
5. Repeat one call to action, worded the same each time.

## Quality checks

- The page asks for exactly one action.
- No claim lacks proof or a marker.
- Prices, dates and terms match approved sources.

## Stop and hand to a person when

- The page states a price, guarantee, result or comparison that is not approved.

## Avoid

- Do not use fake urgency or fake scarcity.
- Do not quote a testimonial without recorded consent.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

A person could review the copy section by section and publish it.
