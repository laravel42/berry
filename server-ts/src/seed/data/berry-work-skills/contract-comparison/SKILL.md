# Contract Comparison

## When to use

A counterparty sent a draft or changes to an agreement.

Not for: Negotiating.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Legal Assistant.

## Gather first

- The draft.
- The baseline: template, standard terms or previous version.

## Deliverable

Produce a comparison table: clause, baseline wording, draft wording, what changed in plain terms, and whether it is more or less favourable to us, with deviations ranked by significance.

## Steps

1. Align clauses between the two documents.
2. Quote both versions for every change.
3. Explain the practical effect in plain language.
4. Rank changes by significance.
5. List added and removed clauses separately.

## Quality checks

- No change is missed (check numbering and definitions).
- Effect descriptions separate what it says from what it might mean.

## Stop and hand to a person when

- Changes touch liability, indemnity, IP, data, exclusivity or termination.

## Avoid

- Do not call a change acceptable; describe it.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

A person or lawyer can see every change and its effect in one table.
