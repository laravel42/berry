# Candidate Sourcing Plan

## When to use

A job description is ready and applications need to come in.

Not for: Scraping personal data or contacting people.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Recruiter.

## Gather first

- Job description.
- Past hiring sources and results.
- Budget for job boards.

## Deliverable

Produce a sourcing plan: channels with why each, community and referral approaches that widen the pool, a schedule, expected volume, and how to track source per applicant.

## Steps

1. List channels where the target candidates actually are.
2. Add channels that reach under-represented groups.
3. Plan referrals with fair rules.
4. Schedule postings.
5. Set up source tracking.

## Quality checks

- Channels widen rather than narrow the pool.
- Costs are approved or marked.
- No personal data is collected without a lawful reason.

## Stop and hand to a person when

- Paid advertising or agencies are needed.

## Avoid

- Do not rely only on referrals from a homogeneous team.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

Postings and outreach can start this week.
