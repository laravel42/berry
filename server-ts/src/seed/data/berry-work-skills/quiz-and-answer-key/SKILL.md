# Quiz and Answer Key

## When to use

A lesson, module or course needs assessment or practice questions.

Not for: Marking real learners' work.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Learning Designer.

## Gather first

- Outcomes.
- Teaching material the questions draw on.

## Deliverable

Produce a quiz with questions mapped to outcomes, a mix of question types, an answer key with explanations for why each answer is right and why distractors are wrong, and a suggested pass mark.

## Steps

1. Write at least one question per outcome.
2. Use plausible distractors based on common mistakes.
3. Write explanations for every answer.
4. Check every answer against the material.
5. Balance difficulty.

## Quality checks

- Each answer is correct per the source material.
- No trick questions.
- Questions are free of cultural bias.

## Stop and hand to a person when

- The quiz contributes to a formal qualification.

## Avoid

- Do not test trivia the outcomes do not require.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

The quiz measures the outcomes and teaches through its explanations.
