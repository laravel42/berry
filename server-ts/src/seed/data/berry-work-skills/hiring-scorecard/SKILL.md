# Hiring Scorecard

## When to use

A job description exists and applications have not been reviewed yet.

Not for: Scoring real candidates; people score.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Recruiter.

## Gather first

- The job description and its outcomes.
- Interview stages planned.

## Deliverable

Produce a scorecard: four to six criteria tied to outcomes, a 1-4 scale with a behavioural description for each level, which stage assesses which criterion, and rules for combining scores.

## Steps

1. Turn each outcome into one or two assessable criteria.
2. Describe what 1, 2, 3 and 4 look like in observable behaviour.
3. Assign each criterion to a stage.
4. Write how panel members score independently before discussing.
5. Add a section for evidence notes per criterion.

## Quality checks

- Criteria relate to the job, not to culture "fit".
- Levels describe behaviour, not impressions.
- No criterion touches a protected trait or proxy.

## Stop and hand to a person when

- The team wants criteria that may be discriminatory.

## Avoid

- Do not include "gut feel" as a criterion.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

Two interviewers using the scorecard would score the same answer similarly.
