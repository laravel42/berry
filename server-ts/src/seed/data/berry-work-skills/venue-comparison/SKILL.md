# Venue Comparison

## When to use

Use when venues must be compared for an event.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Event Planner.

## Gather first

- Event brief.
- Venue options and quotes.

## Deliverable

Produce a comparison: capacity, location and access, accessibility, facilities, catering, cost breakdown, terms and cancellation, availability, and trade-offs.

## Steps

1. Filter venues by capacity and date.
2. Check accessibility and transport.
3. Compare full costs and terms.
4. Summarise trade-offs.

## Quality checks

- Accessibility is assessed for every venue.
- Cancellation terms are recorded.

## Stop and hand to a person when

- A booking, deposit or contract is needed.

## Avoid

- Do not hold or book venues.
- Never send, publish, sign or pay for anything; a person does.
- Never plan an event without naming who is responsible for safety and access.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

A person can choose a venue.
