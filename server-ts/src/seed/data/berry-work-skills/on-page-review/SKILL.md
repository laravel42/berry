# On-Page Review

## When to use

Use when pages must be reviewed for titles, headings, structure and links.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the SEO Specialist.

## Gather first

- Pages.
- Target queries.

## Deliverable

Produce a review: page, title, description, headings, content gaps, internal links, images, issues and fixes.

## Steps

1. Check title and description.
2. Check heading structure.
3. Check content answers the intent.
4. Check links and images.

## Quality checks

- Fixes are specific.
- Intent is answered.

## Stop and hand to a person when

- A change risks traffic to the most important pages.

## Avoid

- Do not stuff keywords.
- Never recommend keyword stuffing, hidden text or bought links.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

Pages are clear to people and search engines.
