# New Starter Payroll Checklist

## When to use

Use when a new starter must be set up in payroll.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Payroll Specialist.

## Gather first

- Start details.

## Deliverable

Produce a checklist: documents needed, tax forms, bank details collection (securely by a person), pension, first pay date.

## Steps

1. List documents.
2. List forms.
3. Note secure collection.
4. Confirm dates.

## Quality checks

- Secure handling is noted.
- Dates are right.

## Stop and hand to a person when

- A payroll run shows an unexplained difference.

## Avoid

- Do not collect bank details in tasks.
- Never run, approve or change payroll.
- Never share one person’s pay with anyone who does not need it.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

New starters are paid correctly.
