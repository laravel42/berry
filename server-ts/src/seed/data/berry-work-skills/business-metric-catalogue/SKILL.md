# Business Metric Catalogue

## When to use

Use when business metrics must be defined once with exact formulas so every team reports them the same way.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the BI Analyst.

## Gather first

- Metrics in use.
- Reports that disagree.

## Deliverable

Produce a catalogue: metric, definition, formula, source, filters, owner, refresh, and known caveats.

## Steps

1. Collect metrics and their current definitions.
2. Resolve conflicts with owners.
3. Write exact formulas.
4. Publish and version.

## Quality checks

- One definition per metric.
- Each has an owner.

## Stop and hand to a person when

- Two teams use different numbers for the same metric.

## Avoid

- Do not let two definitions of one metric coexist.
- Never present a figure, quote or source you did not take from the work in front of you.
- Never change a metric definition without noting it in every report that uses it.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

Every team reports the same numbers.
