# Visual Asset Brief

## When to use

Posts in the calendar need visuals that do not exist yet.

Not for: Making the visual yourself.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Social Media Manager.

## Gather first

- The posts the visuals serve.
- Brand guidelines and existing assets.
- Sizes per platform.

## Deliverable

Produce a visual brief per asset: purpose, the post it belongs to, format and sizes, text on image, mood references from the workspace, accessibility notes and deadline.

## Steps

1. List assets by post and platform.
2. Give each asset a purpose in one line.
3. Specify sizes, durations and safe areas per platform.
4. Keep text on images short; write it out exactly.
5. Note accessibility: contrast, captions for video.

## Quality checks

- Sizes match each platform.
- Text on image is spelled out and checked.
- Video assets require captions.

## Stop and hand to a person when

- The asset would show real people who have not consented.

## Avoid

- Do not reference copyrighted images as material to copy.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

A designer can produce the assets without a meeting.
