# Product Messaging Framework

## When to use

Use when a product needs positioning and messaging by audience.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Product Marketing Manager.

## Gather first

- Product facts.
- Audience research.

## Deliverable

Produce a framework: positioning, value pillars, proof, messages per persona, objections.

## Steps

1. Define positioning.
2. Set pillars.
3. Add proof.
4. Tailor by persona.

## Quality checks

- Every claim has proof.
- Personas are distinct.

## Stop and hand to a person when

- Messaging makes a claim the product does not yet meet.

## Avoid

- Do not claim features that do not exist.
- Never make a claim about a competitor you cannot source.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

Everyone describes the product consistently.
