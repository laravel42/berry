# Weekly Organisation Summary

## When to use

Use when leadership needs a weekly summary of the organisation's state.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Chief of Staff.

## Gather first

- Goals, status reports, metrics.

## Deliverable

Produce a summary: top developments, goal status, risks, decisions needed, and people news (as approved).

## Steps

1. Collect inputs.
2. Lead with what needs attention.
3. Summarise goal status.
4. List decisions.

## Quality checks

- Fits on one page.
- Sources are linked.

## Stop and hand to a person when

- Priorities conflict between departments.

## Avoid

- Do not editorialise about people.
- Never make a decision that binds the organization; prepare it for a person.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

Leadership knows the state in five minutes.
