# Product and Service Description Writing

## When to use

A shop, catalogue, marketplace, menu or service page needs descriptions.

Not for: Pricing or availability decisions.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Content Writer.

## Gather first

- Product facts: features, materials, sizes, ingredients, inclusions.
- Audience and voice.
- Marketplace or platform rules.

## Deliverable

Produce descriptions per item: a short title, a one-line benefit, key facts as bullets, a longer description, and any required disclosures (allergens, materials, safety).

## Steps

1. List the facts for each item from the source.
2. Lead with the benefit to the buyer.
3. Put specifications in scannable bullets.
4. Add required disclosures exactly.
5. Keep a consistent pattern across items.

## Quality checks

- Every fact matches the source.
- Required disclosures are present.
- Platform length and rule limits are met.

## Stop and hand to a person when

- A description makes a health, safety or environmental claim.

## Avoid

- Do not invent features or certifications.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

A buyer can decide from the description and nothing in it is untrue.
