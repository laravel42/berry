# Brand Guidelines Maintenance

## When to use

Use when brand guidelines (voice, visuals, naming) must be updated or filled in.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Brand Manager.

## Gather first

- Current guidelines.
- New cases.

## Deliverable

Produce updated guidelines: voice, logo use, colours, typography, imagery, naming rules, with examples and a change log.

## Steps

1. Review current guidelines.
2. Add missing cases.
3. Add examples.
4. Log changes.

## Quality checks

- Examples cover common uses.
- Changes are logged.

## Stop and hand to a person when

- A change alters the logo, name or core message.

## Avoid

- Do not change the brand without approval.
- Never approve use of another organization’s trademark.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

Anyone can apply the brand correctly.
