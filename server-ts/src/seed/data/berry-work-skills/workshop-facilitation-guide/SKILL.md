# Workshop Facilitation Guide

## When to use

A live session with group activities is planned.

Not for: Booking venues or sending invitations.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Learning Designer.

## Gather first

- Purpose and outcomes.
- Participants and number.
- Duration, room or online tool.

## Deliverable

Produce a facilitator guide: agenda with timings, instructions for each activity as the facilitator will say them, materials and setup, group sizes, fallback plans, and how to capture outputs.

## Steps

1. Lay out the agenda with breaks.
2. Write activity instructions word for word.
3. List setup and materials per activity.
4. Add a fallback if something runs long or fails.
5. Say how outputs are captured and shared.

## Quality checks

- Timings include transitions and breaks.
- Instructions are clear enough to read aloud.
- Accessibility needs are considered.

## Stop and hand to a person when

- The workshop handles sensitive topics (conflict, wellbeing, safety).

## Avoid

- Do not schedule more than ninety minutes without a break.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

A different facilitator could run the session.
