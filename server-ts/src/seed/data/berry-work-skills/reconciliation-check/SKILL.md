# Reconciliation Check

## When to use

Totals look wrong, month end is closing, or two documents disagree.

Not for: Correcting accounting records directly.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Financial Analyst.

## Gather first

- Both sets of records for the same period.
- Known timing items.

## Deliverable

Produce a reconciliation: both totals, matched items, unmatched items on each side with likely reason, the remaining unexplained difference, and suggested follow-ups.

## Steps

1. Confirm both sources cover the same period and currency.
2. Match items by amount, date and reference.
3. List unmatched items on each side.
4. Explain timing differences and duplicates.
5. State the unexplained remainder plainly.

## Quality checks

- Matched plus unmatched equals each total.
- The unexplained remainder is shown, even if zero.

## Stop and hand to a person when

- Unexplained differences remain or patterns suggest error or fraud.

## Avoid

- Do not force a match by plugging a difference.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

Every difference is explained or listed for follow-up.
