# Script Writing

## When to use

Someone will speak the words, on camera, on air or on stage.

Not for: Slide design; the script can list what each slide shows.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Content Writer.

## Gather first

- Speaker, audience, length and setting.
- Key messages and any must-say lines.
- Source material.

## Deliverable

Produce a script with timing marks, speaker lines written to be said aloud, notes for visuals or slides, and an estimated running time.

## Steps

1. Set the running time and divide it into sections.
2. Open with why the listener should care in the first fifteen seconds.
3. Write short spoken sentences; read them aloud in your head.
4. Add visual or slide notes beside the lines they support.
5. Estimate time at roughly 130 to 150 spoken words per minute.

## Quality checks

- The script fits the time slot.
- No sentence needs a breath in the middle.
- Names and numbers are easy to say and are correct.

## Stop and hand to a person when

- The speaker is a public figure or the script speaks on someone's behalf about sensitive matters.

## Avoid

- Do not write for the page; write for the ear.
- Do not put words in a real person's mouth they have not approved.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

The speaker can rehearse from it without rewriting.
