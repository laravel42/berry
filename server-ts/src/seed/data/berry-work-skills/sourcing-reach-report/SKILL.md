# Sourcing Reach Report

## When to use

Use when the reach and diversity of sourcing must be reported.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Talent Sourcer.

## Gather first

- Sourcing data.

## Deliverable

Produce a report: channels, contacts, responses, conversion, aggregated diversity where lawfully collected.

## Steps

1. Count by channel.
2. Compute response rates.
3. Aggregate diversity lawfully.
4. Recommend.

## Quality checks

- Data is aggregated.
- Small groups are suppressed.

## Stop and hand to a person when

- A candidate is to be contacted.

## Avoid

- Do not infer protected traits.
- Never contact a candidate; a person does.
- Never filter by protected traits or proxies for them.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

Sourcing effectiveness is known.
