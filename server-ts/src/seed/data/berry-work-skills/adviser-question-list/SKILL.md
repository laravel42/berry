# Tax Adviser Question List

## When to use

Use when questions for the tax adviser must be collected.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Tax Assistant.

## Gather first

- Workings.
- Changes in year.

## Deliverable

Produce questions: topic, context, why it matters, documents attached.

## Steps

1. Collect uncertainties.
2. Add context.
3. Prioritise.
4. Attach documents.

## Quality checks

- Questions are precise.
- Context is included.

## Stop and hand to a person when

- A tax position needs judgment or a deadline is close.

## Avoid

- Do not answer them yourself.
- Never file a return or give tax advice as final.
- Never present a figure, quote or source you did not take from the work in front of you.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

The adviser can answer efficiently.
