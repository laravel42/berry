# Corrective Action Tracker

## When to use

Use when corrective and preventive actions must be tracked to completion.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Quality Manager.

## Gather first

- Actions from reviews and audits.

## Deliverable

Produce a tracker: action, source, owner, due date, status, evidence of completion, effectiveness check date.

## Steps

1. Record every action with owner and date.
2. Require evidence of completion.
3. Schedule effectiveness checks.
4. Report overdue actions.

## Quality checks

- Closed actions have evidence.
- Effectiveness is checked.

## Stop and hand to a person when

- A defect could harm someone.

## Avoid

- Do not close actions without evidence.
- Never close a corrective action without evidence it worked.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

Actions are done and work.
