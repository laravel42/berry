# Platform Post Adaptation

## When to use

A message, article or announcement must go out on more than one social platform.

Not for: Paid ad targeting and budgets.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Social Media Manager.

## Gather first

- The source message or piece.
- Target platforms.
- Brand voice and any hashtags or handles in use.

## Deliverable

Produce one draft per platform within its limits, with suggested visual, alt text, hashtags only where they help, and the link placement.

## Steps

1. Pull the single most useful idea from the source.
2. Rewrite it natively for each platform: thread, caption, short video hook, professional update.
3. Write alt text for every image.
4. Check character limits and link handling per platform.
5. Read each post alone, without the others, to be sure it stands up.

## Quality checks

- Each draft is within the platform's limit.
- Every image has alt text.
- Tags and mentions refer to accounts that exist and are appropriate.

## Stop and hand to a person when

- A post mentions a real person, customer or partner who has not agreed.

## Avoid

- Do not stuff hashtags.
- Do not tag accounts to get attention.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

Each draft could be posted as written.
