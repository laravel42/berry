# Berry work skills

536 skills for the roles that work without code: eight for each of the
67 specialists in marketing, customers, people, finance and legal,
knowledge, operations, leadership, product, quality and platform work. Each skill is labelled with the catalogue specialist it
belongs to, so a workspace that adds that specialist from Settings → Organization
gets its skills bound automatically. Any skill can also be bound to a custom agent.

Every skill names when to use it, what to gather, the deliverable, the steps,
quality checks, when to stop and hand to a person, what to avoid, and when it is
done. All of them share one rule: the agent drafts, and a person sends,
publishes, pays, signs and decides.

These files are committed as plain Markdown so changes can be reviewed. Edit a
`SKILL.md` and its `manifest.json` entry together; the manifest is what the
seeder reads for the name, role and description.
