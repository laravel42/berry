# Press Release Writing

## When to use

There is approved news and a date it can be shared.

Not for: Distributing it to media; a person does.

Load this skill when this exact piece of work is needed, not merely because the task belongs to the Content Writer.

## Gather first

- The news, its date and embargo, if any.
- Approved quotes from named people.
- Boilerplate and media contact.

## Deliverable

Produce a press release: headline, subhead, dateline, a first paragraph that answers who/what/when/where/why, supporting paragraphs, approved quotes, boilerplate, media contact, and the embargo line if any.

## Steps

1. Write the first paragraph so a journalist could stop there.
2. Add context and supporting facts in order of importance.
3. Insert quotes exactly as approved.
4. Add boilerplate and contact.
5. Check every fact, name, title and date.

## Quality checks

- Quotes are approved and attributed correctly.
- Facts are sourced.
- Embargo and date are correct.

## Stop and hand to a person when

- The release mentions partners, customers or results not approved for publication.

## Avoid

- Do not write quotes for people and present them as said.
- Do not use marketing superlatives.

## Ground rules

- Work from what the workspace holds: the task, its comments and files, the project's resources and linked goals. When something essential is missing, ask in a comment instead of guessing.
- Write the deliverable as a file on the task (or in the project, when the task has one), named for what it is.
- Keep every source next to the claim it supports, and label every assumption as one.
- You draft; a person sends, publishes, posts, pays, signs, books and decides.
- Use personal data only as far as the task needs it, and never repeat it elsewhere.

## Hand back

End with a short note on the task: what you produced and where it is, what you checked, what you assumed, and what a person must decide or verify before it is used.

## Done when

A journalist could write a story from it without calling.
