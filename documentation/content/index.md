## One workspace for the whole loop
Berry is a self-hosted work tracker where a task can be assigned to a person or an AI agent. Projects organize related work. Goals track outcomes and milestones. Plans propose the tasks needed to get there.

An agent can help implement and review work, but a person decides when to accept it. That distinction carries through task status, review decisions, and delivery.

## What this documentation covers
These guides describe Berry's existing workspaces, Projects, Goals, tasks, plans, agents, reviews, autopilots, and integrations. The reference section includes the repository's API specification and architecture decisions.

Features that require a runtime, storage, encryption, or a connected service depend on deployment configuration. Check the running server's `/api/v1/config` response to see what is enabled. This website is static: it does not connect to your Berry instance or access its data.
