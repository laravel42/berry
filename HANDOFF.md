### Per-runtime decisions (doc evidence and outcome)
- **Qoder — WIRED.** Official docs show a local CLI with an in-CLI account login that stays in the CLI: `qoder --acp` runs a stdio Agent Client Protocol server ([docs.qoder.com/cli/acp](https://docs.qoder.com/cli/acp)), the first-run browser sign-in keeps the account token in the CLI's own store ([docs.qoder.com/cli/authentication](https://docs.qoder.com/cli/authentication)), and `qoder --list-models` lists models ([docs.qoder.com/cli/cli-reference](https://docs.qoder.com/cli/cli-reference)). Berry starts `qoder --acp` as a child in the task checkout, reads no credential store, and forwards no PAT or API key (the Qoder PAT CI path is deliberately not used). Mirrors the claude/codex/kiro workstation-login pattern.
- **Hermes — BLOCKED.** The Nous Portal login matches the model, but Hermes documents itself as a shared host "not tied to your laptop" with one principal-wide credential store and a per-invocation stdio session; Berry has not shipped the isolated per-connection boundary ADR-0019 requires. ([programmatic integration](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/developer-guide/programmatic-integration.md), [ACP internals](https://hermes-agent.nousresearch.com/docs/developer-guide/acp-internals), [Nous Portal](https://hermes-agent.nousresearch.com/docs/integrations/nous-portal))
- **Antigravity — BLOCKED.** Launching the official `agy` child with login kept inside it is now supported, but the only headless path (`agy -p`) is documented to hang or emit empty output under a non-TTY subprocess pipe (how Berry would spawn it) and there is no official ACP contract, so there is no working headless child path to wire. ([Codex orchestration ruling](https://discuss.ai.google.dev/t/is-invoking-the-official-antigravity-cli-from-codex-allowed/186952), [non-TTY empty-output defect #318](https://github.com/google-antigravity/antigravity-cli/issues/318))
- **OpenCode, OpenClaw, Pi, Trae CLI, Qwen — BLOCKED (re-checked).** None show an in-CLI per-user subscription account login: OpenCode is a framework whose Claude subscription use Anthropic blocked; OpenClaw is a gateway with provider-owned credentials; Pi reuses another provider's subscription via `/login`; Trae requires provider API keys with no Trae OAuth; Qwen's OAuth is discontinued and `qwen serve` loopback is unauthenticated single-principal with a Coding Plan subscription key.
