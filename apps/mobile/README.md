# Berry mobile

iOS and Android client for the Berry workspace: inbox triage, tasks, calendar, and chat with voice notes and calls.

The screens follow the mobile design in this folder’s original prototype. Data is local fixture state so the app runs without the server. People decide release; agents never mark a task done on their own.

```bash
pnpm install
pnpm dev:mobile
```

Then open the project in Expo Go, an iOS simulator, or an Android emulator.
